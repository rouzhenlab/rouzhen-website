# Review 目录

在此阶段对所有生成的内容进行人工审核，然后发布到社交媒体。

## 审核目的

**网站文章是规范来源** - 每个社交媒体版本都是网站上已发布文章的适配版本。

审核的目的是确保适配版本：
- ✅ 准确反映原文章
- ✅ 适合目标平台
- ✅ 保持品牌一致性
- ✅ 准备好发布

## 审核流程

1. **检查生成的内容** - 查看 `../output/` 中的各平台版本
2. **比对原文** - 与 `journal/entries/` 中的原始文章对比
3. **验证质量** - 检查内容格式、图像和元数据
4. **进行编辑** - 如需要，手动调整任何内容
5. **批准发布** - 仅批准已审核且符合要求的内容
6. **手动发布** - 创作者将批准的内容发布到各平台

## 审核检查清单

### 内容一致性
- [ ] 社交媒体版本准确反映原文章的核心信息
- [ ] 删除的任何内容都是平台适配需要（不是改变含义）
- [ ] 添加的任何元素都是平台格式化要求

### 平台格式
- [ ] 内容符合平台特定格式
- [ ] 标签和主题标签适当
- [ ] 行动号召清晰
- [ ] 链接指向正确的来源

### 品牌一致性
- [ ] 遵循 `brand/voice.md` 的写作风格
- [ ] 遵循 `brand/visual.md` 的视觉标准
- [ ] 水印应用符合 `brand/watermark.md`

### 图像检查
- [ ] 尺寸符合平台规范
- [ ] 水印正确应用（如需要）
- [ ] 图像质量可接受
- [ ] 元数据已清理

## 发布决定

仅在完全满足以下条件后发布：
- ✅ 内容已完全审核
- ✅ 与原文章保持一致
- ✅ 所有格式检查通过
- ✅ 创作者同意发布
- ✅ 没有待处理的编辑

## 版本管理

### 标记批准的内容

在批准的内容上添加时间戳或标记：
```
filename_APPROVED_2026-07-15.md
```

### 追踪修订

如果进行了修改：
```
filename_v1_original.md
filename_v2_revised_APPROVED.md
```

## 社交媒体发布注意事项

### 发布前
- 在对应平台中预览
- 检查所有链接和图像是否正确加载
- 验证格式和排版

### 发布时机
- 考虑平台最佳发布时间
- 协调多平台发布策略
- 记录实际发布时间

### 发布后
- 监控初期互动
- 准备回应评论
- 保存截图以备记录

## 原始来源保护

**重要**: 始终保持 `journal/entries/` 作为规范来源。

- 🔒 website articles = 官方版本
- 📱 social media = 适配版本
- 🎯 Publisher = 适配工具，不替换来源

如果需要修正，请在 `journal/entries/` 中更新原文，然后重新适配。

---

**所有最终发布决定完全由创作者手动做出。没有自动发布机制。**

*社交媒体版本是网站文章的适配版本，而不是独立版本。*

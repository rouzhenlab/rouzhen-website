# ROUZHEN 水印标准

这个文档定义了 ROUZHEN 水印的应用标准。

水印用于保持品牌识别，同时尊重原创艺术作品。

## 水印符号

### 标志
```
～
```

ROUZHEN 品牌符号：波浪号 `～`

这个简洁的符号代表：
- 流动与变化
- 云和雾
- 呼吸和生命
- 连接与对话

## 水印规格

### 颜色
```
白色 (White)
RGB: 255, 255, 255
Hex: #FFFFFF
```

使用纯白色，确保在各种背景上清晰可见。

### 透明度
```
35% 不透明度 (65% 透明)
```

水印应该微妙而不显眼：
- 足够清晰以识别品牌
- 足够轻微以不干扰原始图像
- 尊重艺术作品的完整性

### 风格
```
极简和低调
```

- 无附加装饰
- 无文字说明
- 无边框或背景
- 只有符号本身

## 推荐位置

### 首选：右下角
```
┌─────────────────┐
│                 │
│                 │
│                 │
│                ～│
└─────────────────┘
```

- 不干扰主要构图
- 易于识别
- 保持平衡

### 替代位置

如果内容需要，可以使用：
- **右上角** - 对于某些构图
- **中下方** - 对于人像
- **角落边缘** - 完全最小化干扰

### 避免位置

❌ 不要放在：
- 图像中心
- 主要视觉焦点上
- 文字或关键元素上
- 人脸或脸部上

## 尺寸指导

水印应该相对于图像尺寸：

| 图像宽度 | 水印尺寸 |
|---------|---------|
| 小 (< 600px) | 16-20px |
| 中 (600-1200px) | 20-28px |
| 大 (> 1200px) | 28-40px |

始终保持符号清晰可读，但不过分突出。

## 平台特定应用

### 网站
- 位置：右下角
- 透明度：35%
- 尺寸：根据图像调整

### 微信
- 位置：右下角
- 透明度：35%
- 尺寸：20-24px

### 小红书
- 位置：右下角
- 透明度：35%
- 尺寸：24-28px

### Instagram
- 位置：右下角
- 透明度：35%
- 尺寸：24-32px

## 应用目的

### 品牌认同
- 在所有平台上识别 ROUZHEN 内容
- 建立一致的品牌视觉
- 轻微而优雅的标记

### 原创保护
- 表明内容所有权
- 不妨碍欣赏
- 尊重原始艺术

### 生态完整性
- 承认来源
- 创作者署名
- 维护品牌一致性

## 不应该做的

❌ **避免**：
- 大型、明显的水印
- 多个水印
- 彩色水印
- 带有文本的复杂标记
- 中心位置
- 高于 50% 的不透明度
- 会损害原始图像的应用

## 特殊情况

### 艺术摄影
- 保持最小的存在
- 优先级给予图像
- 可以在某些情况下省略（对于社交媒体故事等）

### 社交媒体帖子
- 标准应用
- 右下角
- 35% 透明度

### 归档或存储
- 水印可选
- 在存储时可能省略原始文件

---

**水印应该像呼吸一样——存在但不可见。它应该增强品牌而不是主导内容。**

*所有水印应用应由创作者手动审核和批准。*

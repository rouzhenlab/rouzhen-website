# ROUZHEN 品牌声音指南

这个文档定义了 ROUZHEN 内容创作的写作风格和品牌声音。

所有内容适配都应遵循这些原则，以保持品牌一致性。

## 品牌声调

ROUZHEN 的声调是：

### 🤫 安静
- 温和而不张扬
- 让内容自己说话
- 避免大声喧哗的营销

### 🎭 诗意
- 充满想象力和比喻
- 诗意的表达方式
- 文学性的语言

### 🔬 科学
- 基于观察和实验
- 有学术基础
- 理性和严谨

### 🔭 探索性
- 提出问题而非给出答案
- 邀请读者思考
- 打开新的视角

### 🚀 面向未来
- 想象未来的可能性
- 当今思想的反思
- 技术与自然的对话

## 核心哲学

**ROUZHEN 探索云、苔藓、自然、技术和人类想象力之间的关系。**

这不仅仅是一个品牌，而是一个思想框架——一个观察和理解世界的方式。

## 写作原则

### ✅ 应该做

- 📖 **讲述有思想的故事** - 引导读者通过叙述进行思考
- 🌱 **使用自然的隐喻** - 用云、苔藓、呼吸等概念表达抽象想法
- ⚖️ **平衡诗意与科学** - 既要有美感又要有可信度
- 💭 **邀请思考** - 留下空间让读者形成自己的结论
- 🔗 **连接想法** - 展示自然与技术、过去与未来之间的联系

### ❌ 应该避免

- 🚫 **廉价广告语言** - 没有真实意义的营销术语
- 🚫 **过度夸大** - 不切实际的承诺或宣称
- 🚫 **奢侈品词汇** - 虚浮的"奢华""独家"等词
- 🚫 **空洞标语** - 没有支撑的口号
- 🚫 **咄咄逼人的语气** - 强硬的销售话术

## 偏好的概念

在内容中频繁使用和回归这些核心概念：

| 概念 | 含义 |
|------|------|
| 🌥️ **云** | 流动、变化、连接 |
| 🌿 **苔藓** | 微小、韧性、生态 |
| 💨 **雾** | 神秘、过渡、朦胧美 |
| 💨 **呼吸** | 生命、节奏、对话 |
| 🌲 **生活生态系统** | 相互联系、共生 |
| 🌍 **未来自然** | 技术与生态的融合 |
| 🔬 **微观景观** | 在小处发现大智慧 |
| 🤝 **自然与技术的对话** | 二者的平衡与融合 |

## 语言示例

### ✅ ROUZHEN 风格

> "苔藓像云一样思考——缓慢地，不断地，通过最细微的变化。"

> "在微观的世界里，我们发现了宏观的真理。"

> "技术不是与自然对立，而是自然的另一种呼吸。"

### ❌ 避免的风格

> "我们的革命性产品改变了一切！"

> "奢华的终极体验等待着您。"

> "限时独家优惠——现在就行动！"

## 平台适配指南

在为不同平台适配内容时，保持这种声调：

- **网站**: 完整的诗意表达，更深入的科学讨论
- **微信**: 温和的故事叙述，适合长文思考
- **小红书**: 视觉化的灵感，简洁的诗意表达
- **Instagram**: 图像优先，简短的冥想性文字

---

**所有内容适配工具应使用这些原则作为参考，确保无论平台如何，ROUZHEN 的声音始终一致。**

*AI 可以协助格式化和调整，但品牌声调的本质必须保持不变。*

# ROUZHEN Publisher Aesthetic Rules

> v1.0 — Content System

## 1. Long = The Creator

**Purpose:** Creator voice / complete narrative

**Rules:**
- Preserve full article body
- Tags must use brand YAML list

**Example:**
```yaml
tags:
  - ROUZHEN
  - 苔藓美学
  - 云雾生态
  - 自然设计
```

## 2. Image = The Seeker (Xiaohongshu)

**Narrative structure:**
Conflict ↓ Search ↓ Discovery ↓ Insight

**Opening rule:**
- Narrative starts from tension or unanswered question
- Preferred: I thought... I wondered... I wanted to know...
- Avoid: Technical nouns as first sentence

**Forbidden:**
- Start with conclusion
- Start with philosophy
- Start with realization

## 3. Photo = The Observer (Instagram)

**Role:** Photo is the protagonist.

**Allowed:**
- Visual
- Sensory
- Philosophy
- Photographer presence without intrusion

**Forbidden:**
- Research process
- Patent
- Engineering
- Personal struggle
- Development diary
- Author as story subject
- Personal narrative transitions: I discovered, I realized, I learned

**English hashtags only.**

## 4. Micro = The Philosopher

**Format:** Two-line philosophy.

**Chinese:** Visual + insight

**English:** Brand philosophy, not translation.

**Avoid:**
- Research/process language
- First person: I, me, my
- Personal diary tone
- Quotation/dialogue
- Words: thought, felt, realized, discovered

**Voice:** Brand consciousness, not author diary.
